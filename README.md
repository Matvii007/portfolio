# Портфолио — Matvii Gerasymenko

Одна страница, без сборки и зависимостей. Открывается двойным кликом по `index.html`.

```
index.html   вся разметка и весь скрипт
style.css    все стили
assets/      видео, постеры, фотография
```

## Залить на GitHub Pages

Терминал не нужен.

1. Заходишь на **github.com** → зелёная кнопка **New** → имя `portfolio` → **Public** → **Create repository**.
2. На пустой странице репозитория жмёшь ссылку **uploading an existing file**.
3. Открываешь в Finder папку `~/Desktop/site`, выделяешь **всё, что внутри** (⌘A) — `index.html`, `style.css`, `README.md` и папку `assets` — и перетаскиваешь в окно браузера.
   Саму папку `site` перетаскивать НЕ надо, только её содержимое.
4. Ждёшь, пока догрузятся 10 МБ, и жмёшь **Commit changes**.
5. **Settings → Pages → Source: Deploy from a branch → Branch: main → папка / (root) → Save.**
6. Через 1–2 минуты обновляешь страницу Pages — там появится адрес вида
   `https://твой-логин.github.io/portfolio/`

Обновить потом: заходишь в репозиторий → **Add file → Upload files** → перетаскиваешь изменённые файлы → Commit.

## Что где править

| Что | Где |
|---|---|
| Имя, подзаголовок, город | `index.html`, блок `.hero` |
| Фраза-заявление под первым экраном | `index.html`, блок `.claim` |
| Описания работ | `index.html`, блоки `.proj` |
| Почта и ссылки | `index.html`, блок `.links` |
| Кислотный цвет | `style.css`, `--acid` в самом верху |
| Размер фотографии в имени | `style.css`, `.portrait { width: ... }` — и второе такое же правило в блоке `@media (max-width:900px)` |

## Видео

Исходники были 1920×1080 и весили 11, 39 и 52 МБ. Пережаты в 1280×720,
H.264 CRF 27, звук AAC 96k, `+faststart` — теперь 2, 3 и 5 МБ.
Постеры сняты со второй секунды каждого ролика.

Заменить ролик:

```bash
ffmpeg -i исходник.mp4 -vf scale=1280:-2 -c:v libx264 -crf 27 -preset slow \
  -pix_fmt yuv420p -movflags +faststart -c:a aac -b:a 96k assets/имя.mp4
ffmpeg -ss 2 -i исходник.mp4 -vf scale=1280:-2 -frames:v 1 -q:v 4 assets/имя-poster.jpg
```

Ролики не грузятся, пока не появятся на экране, и играют без звука.
Звук включается кнопкой на самом ролике; при включении звука остальные глушатся.

## Чего на сайте нет и почему

Ни количества клиентов, ни лет опыта, ни процентов владения программами.
Всё это было бы выдумано, а выдуманные цифры на портфолио проверяются
за минуту и стоят дороже, чем их отсутствие. Место занимает то, что можно
показать: три ролика и то, как идёт работа.

Murmur подписан как концепт прямо в карточке — заказчика у него не было.
