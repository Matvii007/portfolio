# Сайт-портфолио

Три страницы, без сборки, без зависимостей. Открывается двойным кликом по `index.html`.

```
index.html          профиль
work.html           список работ
runtime.html        кейс Runtime
style.css           общий стиль всех страниц
assets/
  matvii.jpg        ← ТВОЁ ФОТО, заменить
  runtime.mp4       видео, 15 МБ
  runtime-poster.jpg  обложка плеера
  runtime-still-1..4.jpg  кадры на странице кейса
```

---

## 1. Поставить фото

Сохрани портрет как **`assets/matvii.jpg`**, поверх заглушки, которая там сейчас лежит.

Требования: вертикальный, пропорции близко к 4:5, ширина 720–1000 px, вес до 300 КБ.
Если фото тяжелее — сожми:

```bash
cd ~/Desktop/site/assets
ffmpeg -i исходник.jpg -vf "scale=800:-2" -q:v 4 matvii.jpg -y
```

Обрезать под 4:5 браузер умеет сам (`object-fit: cover`), но лучше кадрировать вручную,
чтобы лицо не съехало.

## 2. Вписать свои ссылки

В `index.html` найди блок `Contact`. Там две заглушки:

```html
<li><a href="#" data-fill="linkedin">LinkedIn</a></li>
<li><a href="#" data-fill="x">X</a></li>
```

Подставь настоящие адреса вместо `#` и убери `data-fill`.
Если какой-то соцсети не будет — просто удали строку целиком.

## 3. Опубликовать на GitHub Pages

Один раз:

1. Заведи репозиторий с именем **`ИМЯ-АККАУНТА.github.io`** — именно так, иначе адрес будет длинным.
2. В папке сайта:

```bash
cd ~/Desktop/site
git init
git add .
git commit -m "portfolio"
git branch -M main
git remote add origin https://github.com/ИМЯ-АККАУНТА/ИМЯ-АККАУНТА.github.io.git
git push -u origin main
```

3. В репозитории: `Settings` → `Pages` → `Source: Deploy from a branch` → ветка `main`, папка `/ (root)`. Сохранить.

Через 1–2 минуты сайт будет по адресу `https://ИМЯ-АККАУНТА.github.io`.

Дальше любое обновление:

```bash
cd ~/Desktop/site
git add .
git commit -m "что поменял"
git push
```

## 4. Добавить новую работу

1. Скопируй `runtime.html` → `новое-имя.html`, перепиши текст внутри.
2. Положи видео и кадры в `assets/`.
3. В `work.html` скопируй блок `<a class="work-card">` и поменяй ссылку, обложку и подписи.

Ничего больше трогать не нужно — стиль общий.

## Технические заметки

- Видео сжато в H.264, CRF 22, `+faststart` — начинает играть до полной загрузки.
- У GitHub Pages лимит трафика ~100 ГБ в месяц. При весе 15 МБ это около 6500 полных
  просмотров в месяц. Если когда-то упрёшься — перенеси на Cloudflare Pages,
  там трафик не лимитирован и тоже бесплатно.
- Файл в git больше 100 МБ не примут. Держи видео под 50 МБ.
- Каждая новая версия видео остаётся в истории git навсегда. Не коммить по десять раз —
  сначала доводи файл, потом клади.
