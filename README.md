# Портфолио — Matvii Gerasymenko

Статический сайт без сборки и зависимостей. Живой адрес: https://matvii007.github.io/portfolio/

```
index.html              главная: продуктовые ролики для AI и SaaS
films/index.html        AI-фильмы: список кейсов
films/dew/index.html    кейс DEW (собирается скриптом, см. ниже)
films/dew/media/        кадры, сравнения, тизер кейса
films/dew/hls/          фильм адаптивным потоком: 1080p / 720p / 480p, сегменты по 4 с
agencies/index.html     страница для студий (noindex)
style.css               вся дизайн-система
assets/js/site.js       поведение: ролики по видимости, звук, вкладки, до/после, лайтбокс, плеер
assets/js/hls.light.min.js   hls.js 1.5.17, грузится только по нажатию Play
assets/fonts/           Inter, Instrument Serif, JetBrains Mono (латиница, woff2)
```

## Дизайн — из скилла motion-design

- Палитра — пресет `paper-single-hot`: бумага #F9F9F9, тёмный акт #181818, чернила #262626, акцент #FA5D18 — одно слово на строку.
- Шрифты: один гротеск 500 для утверждений (Inter), serif для имён (Instrument Serif), моно для меток (JetBrains Mono).
- Композиция: один герой на экран, много пустоты, волосяная рамка на 5,5 % от краёв экрана, окна с контактной тенью firecrawl, конструкционные направляющие (пунктир от краёв) у заголовков разделов.
- Главная светлая, страницы AI-фильмов тёмные (`body.night`).

## Скорость

- Первая загрузка главной ≈ 140 КБ (HTML 3 + CSS 6 + JS 1,5 КБ в gzip, шрифты, портрет 9 КБ).
- Ролики `preload="none"`, играют только когда видны. Картинки WebP, `loading="lazy"`.
- Фильм DEW — HLS: стартует с 480p и поднимается до 1080p по скорости сети. Safari играет HLS сам, остальным по нажатию Play подгружается hls.js.
- К `style.css` и `site.js` в страницах приписана версия (`?v=1118`): после правки CSS/JS увеличить число во всех страницах, чтобы у посетителей не застрял старый файл.

## Кейс DEW — как пересобрать

Скрипты в `~/Documents/scripts/super agent/_site_build/`:
- `build_media.py` — все картинки и короткие ролики кейса из мастера, блокаутов и кадров;
- `case_template.html` + `build_case.py` — страница кейса; таймлайн AE берётся из экспорта проекта (`~/aejobs/export_timeline.jsx`), музыкальная дуга — из стема музыки.

## Залить на GitHub Pages

Через веб-загрузку GitHub (Add file → Upload files) в нужную папку репозитория, файлы не больше 25 МБ. Сегменты фильма по 1–4 МБ.

## Видео на главной

1280×720, H.264 CRF 27, AAC 96k, `+faststart`. Постер — WebP со второй секунды.

```bash
ffmpeg -i исходник.mp4 -vf scale=1280:-2 -c:v libx264 -crf 27 -preset slow \
  -pix_fmt yuv420p -movflags +faststart -c:a aac -b:a 96k assets/имя.mp4
```

## Чего на сайте нет и почему

Ни количества клиентов, ни лет опыта, ни процентов владения программами. Выдуманные цифры проверяются за минуту и стоят дороже, чем их отсутствие. Концепты подписаны как концепты.
